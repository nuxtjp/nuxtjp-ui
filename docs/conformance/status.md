## 検証方法

```sh
node scripts/verify-compliance.mjs
node scripts/check-upstream.mjs
```

1つ目はmodule内の参照、成果物、カバレッジ、互換性差分を確認します。2つ目は外部の一次情報を読み取り、差分を `review-required` として返します。外部検査はlockや実装を書き換えません。
